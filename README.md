# MS ZODIAC - Refactored Build

تم تقسيم النسخة الأصلية إلى طبقات بدون إعادة تصميم الواجهة:

- `index.html` الهيكل فقط
- `styles.css` كل CSS
- `data.js` البيانات الثابتة: الأبراج، الأنماط، الأسئلة، الخرائط وغيرها
- `script.js` الحسابات، الـ UI، التفاعلات والرندر
- `security.js` طبقة المراقبة الأمنية الموجودة في النسخة الأصلية

## الأداء
- دعم `prefers-reduced-motion`
- تقليل الحركات على أجهزة اللمس
- الحفاظ على `overflow-x: hidden`
- عدم تغيير منطق الموقع أو بياناته أثناء عملية الفصل

## ملاحظة
البيانات ما زالت JavaScript client-side لأنها كانت كذلك في الملف الأصلي. هذا فصل تنظيمي للصيانة، وليس حماية حقيقية للأسرار. أي بيانات موجودة في واجهة المتصفح تعتبر قابلة للاطلاع.
